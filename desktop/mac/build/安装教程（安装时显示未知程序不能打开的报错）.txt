教学管理系统 macOS 客户端
安装教程（安装时显示未知程序不能打开的报错）
================================================================

先说结论
--------
下面这些提示**都不是文件损坏，也不是中毒**：

  ·「"教学管理系统"已损坏，无法打开。你应该将它移到废纸篓。」
  ·「无法打开"教学管理系统"，因为它来自身份不明的开发者。」
  ·「Apple 无法检查"教学管理系统"是否包含恶意软件。」

原因是：本客户端是实验室内部工具，没有购买苹果开发者账号（每年 99 美元），
所以没有官方签名，macOS 出于安全默认会拦一下。**按下面的步骤放行一次，
以后就能正常双击打开了。**


第 0 步：先安装
----------------
1. 双击这个 .dmg 文件，等它挂载出一个窗口；
2. 把窗口里的「教学管理系统」图标，**拖进右边的「应用程序」文件夹**；
3. 到「启动台」或「应用程序」里找到它，双击打开。

注意：请**一定先拖进「应用程序」**再打开。直接双击 DMG 里的图标，
macOS 会启用"路径随机化"，容易导致自动更新等功能异常。


第 1 步：遇到弹窗时，先点"完成"
----------------------------------
双击后如果出现上面任何一种提示，**点「完成」或「好」把弹窗关掉**。

  ⚠️ 千万不要点「移到废纸篓」——点了会真把 App 删掉，需要重新下载。


第 2 步：在系统设置里放行（推荐，不用敲命令）
------------------------------------------------
1. 点屏幕左上角苹果图标  →「系统设置」；

2. 左侧找到并点开「隐私与安全性」；

3. 右侧内容一直往下拉，找到「安全性」这一栏，会看到一行类似：

     「已阻止使用"教学管理系统"，因为来自身份不明的开发者」

4. 点这一行右边的「仍要打开」按钮；

5. 系统再弹一次确认框，点「打开」（可能需要验证指纹或开机密码）；

6. 完成。以后在「应用程序」里双击就能直接打开了。


第 3 步：如果上面那一行没有出现
----------------------------------
· 确认你已经**双击过一次 App 并触发了拦截**，这一栏才会出现；
· 关掉系统设置窗口，重新打开一次再看看；
· 还是没有的话，直接用下面的备选方法（一步到位）。


备选方法：一行命令搞定（10 秒）
----------------------------------
1. 打开「启动台 → 其他 → 终端」（或按 Command + 空格，输入"终端"回车）；

2. 复制下面整行，粘贴进终端，按回车：

     sudo xattr -cr /Applications/教学管理系统.app

3. 提示输入密码时，输入你的**开机密码**，然后回车。
   （输入过程中屏幕上不会显示任何字符，这是正常的，不是卡住了。）

4. 没有报错就说明成功了。回到「应用程序」，双击「教学管理系统」即可打开。


常见问题
--------
Q1：为什么不能做成直接双击就能打开？
A：苹果要求应用必须用付费开发者证书签名并公证，费用是每年 99 美元。
   实验室目前没买，所以需要手动放行一次。

Q2：这个提示每次都会出现吗？
A：只在**第一次打开**时出现，放行一次即可。
   以后客户端自动更新到新版本后，可能会再拦一次，按同样步骤处理就行。

Q3：点了「仍要打开」没反应 / 还是打不开怎么办？
A：用备选方法执行一次那条命令，基本都能解决。
   仍不行的话，确认一下 App 是不是放在「应用程序」文件夹里（而不是 DMG 里）。

Q4：会不会有安全风险？
A：这是我们自己实验室开发并公开的客户端，源码可在网站下载自行核对。
   系统提示只是因为"没有付费签名"，不代表包含恶意软件。

Q5：提示「已损坏，无法打开」也能用上面的方法吗？
A：能。这条提示同样只是签名未被认可导致的，处理方式完全一样。
   （注意：「已损坏」的弹窗里没有"打开"按钮，所以要点「完成」，
     再去系统设置里放行，或直接用备选命令。）

Windows 桌面客户端正式版，本版重点：

1) 全新桌面外壳：自绘标题栏、工具栏、侧边导航与状态栏，不再是浏览器窗口的样子。
2) 新增在线升级（OTA）：启动时与运行期间自动检查新版本，工具栏会亮起「新版本」徽标，点击即可查看更新内容并升级。
3) 独立的「软件更新」对话框：版本对比、更新内容、安装包体积与 SHA-512 校验一屏可见。
4) 更新包下载带实时进度与速度显示，可随时取消；下载完成后按字节数与 SHA-512 双重校验，不通过自动丢弃并提示重下。
5) 安装版调起标准安装向导完成升级；绿色版自动原地替换并重新启动，无需手动重装。
6) 应用菜单与账户菜单改用系统原生菜单，观感与 Windows 资源管理器一致。
7) 登录态持久化、下载进度提示、断网离线页等体验细节继续完善。

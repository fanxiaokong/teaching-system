1.4.4 更新说明

【全新界面：与 macOS 客户端统一为同一套外壳】
- 改为 bilibili 式排版：顶部一条 56px 通栏（品牌 + 分类标签 + 搜索 + 窗口按钮），
  左侧 76px 纯图标导航栏，底部状态栏显示连接状态与当前地址。
- 左侧导航改为图标 + 文字的竖排磁贴，鼠标悬停有浮层说明。
- 观感与 macOS 客户端完全一致，两个平台只有窗口按钮不同：
  Windows 保留右上角「最小化 / 最大化 / 关闭」，macOS 用系统原生左上角红绿灯。

【导航调整】
- 侧边栏「工具」分组现在只有「工具箱」一个入口（原「App 下载」已于 1.4.2 移除，
  「格式转换」已于 1.4.3 并入工具箱页）。
- 顶部应用菜单同步新增「工具箱」。

【修复】
- 修复折叠/展开左侧导航后网页内容区与侧栏错位（主进程收到的显示/隐藏标志极性反了，
  折叠后内容会盖住侧栏或留一条白边，且错误状态会被保存到配置里）。

【升级方式】
- 安装版 / 绿色版打开客户端后自动提示更新，点「立即更新」即可。

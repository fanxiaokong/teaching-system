macOS 客户端 · 开发迭代教程

下载 macOS 端源代码（zip）

教你用 Electron + 原生外壳 继续开发这个 macOS 客户端：装依赖、跑起来、改界面、打包、发新版让客户端 OTA 自动升级。

这个客户端是「原生桌面外壳 + 站点实时内容」：窗口、标题栏、工具栏、侧栏、菜单、OTA 升级都在源码里，页面内容直接加载 your-server.example.com 真实站点。所以大部分「改界面」其实是改站点网页，只有改外壳/升级逻辑才需要动这份源码。

0. 一句话理解这个项目

客户端 = Electron 主进程（main.js，管窗口/菜单/下载/升级） + 外壳页面（shell.html 等，管标题栏/工具栏/侧栏） + 内容视图（加载站点真实页面）。改窗口、工具栏、升级逻辑 = 改这份源码；改页面内容 = 改站点（服务端 Flask 代码和模板）。

1. 装依赖、跑起来

# 进入解压后的 MacosAPP 目录
cd MacosAPP

# 国内镜像（否则 Electron 二进制下载极慢/失败）
export ELECTRON_MIRROR="https://registry.npmmirror.com/-/binary/electron/"
export npm_config_registry="https://registry.npmmirror.com"

# 装依赖（仅首次）
npm install

# 直接跑起来（开发模式）
npm start

跑起来后会看到一个无边框的窗口，标题栏、工具栏、侧栏都是源码画的，中间加载的是真实站点。

4. 打包（DMG + ZIP，arm64）

# 未签名打包（当前没有开发者证书，identity 设为 null）
CSC_IDENTITY_AUTO_DISCOVERY=false npm run dist

产物在 MacosAPP/dist/：

  • 教学管理系统-1.0.0-arm64.dmg — 磁盘镜像（双击挂载，拖进「应用程序」安装）
  • 教学管理系统-1.0.0-arm64-mac.zip — 压缩包（备用下载通道）

未签名提醒：没有 Apple 开发者证书，打出来的 dmg 会被 Gatekeeper 拦截。用户首次打开需右键「打开」或在终端执行 xattr -cr /Applications/教学管理系统.app 后再打开。签了名才能双击直接开、才能静默原地升级。

5. 发布新版（让客户端 OTA 自动升级）

改完代码后，把 package.json 里的 version 递增（如 1.0.0 → 1.0.1），重新打包，然后用发版脚本上传并登记：

# 发版脚本会自动：上传 dmg → 算 SHA-512 → 写 app_versions(platform='mac') → 标记最新版
# 服务器口令走环境变量（与网站其它发布脚本一致）
export LC_PASS='<你的服务器口令>'

python3 tools/publish_mac.py "dist/教学管理系统-1.0.1-arm64.dmg" \
    --version-name 1.0.1 --version-code 1000001 \
    --notes "本次更新说明"

发布完成后：

  • https://your-server.example.com/download 立刻显示新版本和 DMG 安装包
  • 已装客户端下次检查时（启动后 8 秒 / 运行中每 6 小时）自动收到更新提示

版本号 version_code 由版本名自动推导（1.0.1 → 1000001，见 db.semver_code），不用手填整数。渠道固定是 mac（客户端 updater.js 里 channel='mac'）。

也可以走网页后台：登录 → 「管理」→「版本管理」，选平台、上传安装包、填版本名和更新说明，效果一样。

6. OTA 升级是怎么工作的（重点）

启动 8 秒后 / 每 6 小时
      ↓
GET /api/v1/app/version?platform=mac&version_code=…
      ↓ 服务端返回 need_update=true
工具栏亮徽标「新版本」+ 系统通知
      ↓ 用户点开
「软件更新」对话框（独立模态窗口）
   ├─ 版本对比 / 更新说明 / 体积 / SHA-512
   ├─ 立即更新 → 下载（进度 + 速度，可取消）
   ├─ 下载完 → 核对磁盘字节数 + SHA-512 → 落地正式安装包
   ├─ 立即安装并退出
   │    └─ macOS：shell.openPath 挂载 dmg → 弹出访达窗口
   │       用户把新 App 拖进「应用程序」覆盖旧版 → 客户端已退出
   └─ 稍后提醒 / 跳过此版本（可恢复）

macOS 受限于 Gatekeeper / 签名，无法像 Windows 那样静默原地替换 .app，所以升级采用「下载安装包 → 打开（dmg 挂载）→ 用户手动拖入『应用程序』→ 退出客户端」的方式。只要能下载、能打开就算具备升级条件（updater.js 里恒为 canAutoUpdate=true）。

7. 必知的坑（都踩过，别重蹈）

坑说明与对策
未签名 dmg 打不开没有开发者证书，Gatekeeper 会拦。首次打开右键「打开」，或 xattr -cr /Applications/教学管理系统.app 清隔离属性。要双击直开、要静默升级，必须签 Developer ID + 开公证（notarization）。
下载 100% 却卡在「下载中」Electron net 流大文件偶发不派发 end 事件。完成判定要用「已收字节数 ≥ Content-Length」+ 磁盘实际大小核对，另有空闲看门狗兜底。
SHA-512 校验总不通过库和 publish_mac.py 统一存 hex（base64 大小写敏感，任何 toLowerCase 都会弄坏）。客户端两种编码都认，但库里只存 hex。
点了「安装」客户端退出了，但没升级这是 macOS 的预期行为：客户端打开 dmg 后主动退出，由你手动把新 App 拖进「应用程序」覆盖。等签了名才能做到真正的原地静默升级。

9. 技术栈速查

Electron 33 + 原生 WebContentsView（内容区）+ electron-builder 25（DMG + ZIP，arm64，未签名）。外壳 UI 是纯 HTML/CSS/JS（无框架）；服务端是 Flask + SQLite + Apache/mod_wsgi。App 标识 com.teachingsystem.desktop，显示名 教学管理系统。macOS 渠道名 mac，与 Windows 的 windows / windows-portable、Android 的 android 并列。

教学管理系统 App · 开发迭代指南

下载完整源代码（zip）

教你用 Android Studio 继续开发这个 App：打开、改界面、实时预览、打包、发新版自动更新。

全程照着做即可。工程里的 JDK、镜像、路径都已配置好，你只管写界面代码。

0. 一句话理解这个项目

App 界面全部用 Jetpack Compose（Kotlin） 手写，数据从网站接口 https://your-server.example.com/api/v1/... 拉取。改界面 = 改 .kt 文件；发新版 = 版本号 +1 → 打包 → 后台发布。

1. 首次打开工程

1. 解压 teaching-system-android-source.zip

2. 打开 Android Studio（是 Android Studio，不是 IntelliJ IDEA）

3. 菜单 File → Open，选中解压出来的 android/ 文件夹（里面那层 android，不是最外层）

4. 等右下角进度条走完（首次同步 3~5 分钟，自动从国内镜像下载 Compose 依赖）

5. 成功标志：底部出现 Gradle sync finished，左侧 app 目录变成正常模块

若弹出 "Module not specified"：说明同步没完成，点工具栏大象图标（Sync Project with Gradle Files）再同步一次，别在弹窗里乱选。

3. 改界面 + 实时预览（最常用）

这是「左边代码、右边实时界面」：

1. 左侧展开 ui/screens/，双击打开 HomeScreen.kt

2. 滚动到文件最底部，找到 @Preview 开头的那段

3. 点 @Preview 左上角的分屏预览图标（Split）

4. 右边立刻渲染出首页，改文字/颜色/布局，Cmd+S 保存，右边实时刷新

想改什么去哪改
首页标题文字HomeScreen.kt 里 Text("一起把网络玩明白")
主题色ui/theme/Theme.kt 的 val Primary = Color(0xFF1F4E79)
底部导航栏项ui/App.kt 的 tabs 列表
App 图标改 gen_icon.py 的 C_TOP/C_BOTTOM 颜色或 "NL" 文字

只有 Android Studio 支持 Compose 预览，IDEA 社区版看不到。

4. 加一个新页面（完整示例）

假设加一个「关于我们」页。① 新建 ui/screens/AboutScreen.kt：

package com.teachingsystem.web.ui.screens

import androidx.compose.foundation.layout.*
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.teachingsystem.web.ui.SimpleTopBar

@Composable
fun AboutScreen(onBack: () -> Unit) {
    Column(Modifier.fillMaxSize()) {
        SimpleTopBar("关于我们", onBack = onBack)
        Text("教学管理系统，欢迎你", Modifier.padding(20.dp))
    }
}

② 在 ui/App.kt 里注册路由：

// Routes 里加一行
const val ABOUT = "about"

// NavHost 里加一行
composable(Routes.ABOUT) { AboutScreen(onBack = { navController.popBackStack() }) }

③ 在某个页面加跳转按钮（例如 MeScreen.kt）：

TextButton(onClick = { navController.navigate(Routes.ABOUT) }) { Text("关于我们") }

5. 打包 APK（两种方式）

方式 A：Android Studio —— Build → Build App Bundle(s) / APK(s) → Build APK(s)，完成后右下角 locate 打开，APK 在 app/build/outputs/apk/debug/app-debug.apk

方式 B：命令行（无需打开 IDE）

cd android
./build_android.sh

6. 版本号管理（配合在线更新，重点）

每次发新版，必须在 android/app/build.gradle.kts 里递增版本号：

defaultConfig {
    versionCode = 3   // ★ 每发一版 +1（整数，用于判断是否更新）
    versionName = "1.2"  // ★ 给人看的版本名
}

versionCode：整数，必须比上一版大，手机靠它判断有没有新版本；versionName：显示用，格式随意。

7. 发布新版（让用户手机自动更新）

改代码 → versionCode +1 → 打包 APK
   ↓
网站登录 → 右上角「管理」→ 顶部「版本管理」
   ↓
上传新 APK → 版本号填整数(如 4) → 版本名 → 更新说明 → 点「发布」
   ↓
用户手机 App 下次打开（或「我的 → 检查更新」）自动弹窗 → 一键更新

手机现在装的是 v1.2（versionCode=3）。之后改完代码、把 versionCode 改成 4、发布后，手机上就会自动收到更新。

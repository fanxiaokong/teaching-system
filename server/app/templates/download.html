macOS 客户端（Apple 芯片 / Intel 通用）

为 Mac 打包的原生桌面客户端，窗口、工具栏、侧栏与 Windows 版一致。安装包已做代码签名，首次打开按下方说明处理一次即可正常使用。

下载 macOS 客户端（.dmg）
首次打开提示「无法打开 / 已损坏」怎么办
客户端没有购买苹果开发者签名证书，所以 macOS 第一次会拦一下。不是文件坏了，按下面的步骤放行一次，以后就能正常双击打开了。
方法一：在系统设置里允许打开（推荐）
  1. 双击 App，弹窗里点「完成」——千万不要点「移到废纸篓」，点了会真删掉。
  2. 点屏幕左上角 →「系统设置」→「隐私与安全性」。
  3. 右侧内容往下拉，找到「安全性」一栏，会看到：
    已阻止使用"教学管理系统"，因为来自身份不明的开发者
  4. 点这一行右边的「仍要打开」。
  5. 再弹一次确认框，点「打开」（需要验证指纹或开机密码）。
  6. 完成 ✅ 以后在「应用程序」里双击就能直接打开。
小提示：如果看不到「安全性」那一栏，先双击一次 App 触发拦截，这一栏才会出现；关掉系统设置重开一次也能刷新出来。
方法二：一行命令搞定（10 秒，不用找设置）
sudo xattr -cr /Applications/教学管理系统.app
在「启动台 → 其他 → 终端」里粘贴执行，输入开机密码后回车（输入时屏幕不显示字符是正常的）。
安装包里也附了一份《安装教程（安装时显示未知程序不能打开的报错）.txt》，随时可以对照着看。

  • 推荐用 ZIP 版：解压出来就是同一个安装包，浏览器不会触发「可执行文件」拦截。

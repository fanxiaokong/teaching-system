# 教学管理系统 App · Android Studio 开发迭代指南

这份指南教你**在 Android Studio 里继续开发这个 App**：怎么打开、怎么改界面、怎么实时预览、怎么打包、怎么发新版让手机自动更新。

> 全程照着做即可。工程里的 JDK、镜像、路径都已经配置好，你只管写界面代码。

### 跨电脑开发（离线包）

这个工程**已经自带 Gradle 发行版**（`android/gradle/gradle-8.10.2`，约 145MB），所以：

- **换一台电脑（Mac / Windows / Linux）解压后，命令行构建不需要再下载 Gradle**
- 需要联网的部分只剩「首次构建的依赖包」（Compose 等，已配国内镜像，几分钟下完）
- 环境要求只有两个：**JDK 17** + **Android Studio（带 SDK）**

| 平台 | 命令行构建命令 |
|---|---|
| macOS / Linux | `cd android && ./build_android.sh` |
| Windows | `cd android && build_android.bat` |

> 脚本会自动探测 JDK17 和 Android SDK 路径；找不到会给出明确提示。

## 0. 一句话理解这个项目

App 界面全部用 **Jetpack Compose（Kotlin）** 手写，数据从网站接口（`https://your-server.example.com/api/v1/...`）拉取。改界面 = 改 `.kt` 文件；发新版 = 版本号 +1 → 打包 → 后台发布。

## 1. 首次打开工程

1. 解压 `LinkCoffee-android-source.zip`
2. 打开 **Android Studio**（注意：是 Android Studio，不是 IntelliJ IDEA）
3. 菜单 `File → Open`，选中解压出来的 **`android/` 文件夹**（是里面那层 `android`，不是最外层）
4. 等右下角进度条走完（**首次同步 3~5 分钟**，会自动从国内镜像下载 Compose 依赖，耐心等）
5. 成功标志：底部出现 `Gradle sync finished`，左侧 `app` 目录变成正常模块

> 若弹出 "Module not specified"：说明同步没完成，点工具栏**大象图标 🐘**（Sync Project with Gradle Files）再同步一次，别在弹窗里乱选。

## 2. 目录结构（改哪里）


## 3. 改界面 + 实时预览（最常用）

这是你之前最想要的「左边代码、右边实时界面」：

1. 左侧展开 `ui/screens/`，双击打开 `HomeScreen.kt`
2. 滚动到文件**最底部**，找到 `@Preview` 开头的那段
3. 点 `@Preview` 左上角的 **分屏预览图标**（Split）
4. **右边立刻渲染出首页**，你改文字/颜色/布局，`Cmd+S` 保存，右边实时刷新

改几处常见东西试试：

| 想改什么 | 去哪改 |
|---|---|
| 首页标题文字 | `HomeScreen.kt` 里 `Text("一起把网络玩明白")` |
| 主题色 | `ui/theme/Theme.kt` 的 `val Primary = Color(0xFF1F4E79)` |
| 底部导航栏项 | `ui/App.kt` 的 `tabs` 列表 |
| App 图标 | 改 `gen_icon.py` 里的 `C_TOP/C_BOTTOM` 颜色或 `"NL"` 文字，重跑脚本 |

> 只有 Android Studio 支持 Compose 预览，IDEA 社区版看不到。

## 4. 加一个新页面（完整示例）

假设加一个「关于我们」页：

1. 新建 `ui/screens/AboutScreen.kt`：

```kotlin
package com.teachingsystem.web.ui.screens

import androidx.compose.foundation.layout.*
import androidx.compose.material3.Text
import androidx.compose.runtime.Composable
import androidx.compose.ui.Modifier
import androidx.compose.ui.unit.dp
import com.teachingsystem.web.ui.SimpleTopBar

@Composable
fun AboutScreen(onBack: () -> Unit) {
    Column(Modifier.fillMaxSize()) {
        SimpleTopBar("关于我们", onBack = onBack)
        Text("教学管理系统，欢迎你", Modifier.padding(20.dp))
    }
}
```

2. 在 `ui/App.kt` 里注册路由：

```kotlin
// Routes 里加一行
const val ABOUT = "about"

// NavHost 里加一行
composable(Routes.ABOUT) { AboutScreen(onBack = { navController.popBackStack() }) }
```

3. 在某个页面加跳转按钮（例如 `MeScreen.kt`）：

```kotlin
TextButton(onClick = { navController.navigate(Routes.ABOUT) }) { Text("关于我们") }
```

## 5. 打包 APK（两种方式）

**方式 A：Android Studio 图形界面**
- `Build → Build App Bundle(s) / APK(s) → Build APK(s)`
- 完成后右下角弹 `locate`，APK 在 `android/app/build/outputs/apk/debug/app-debug.apk`

**方式 B：命令行（无需打开 IDE，工程自带 Gradle，不用下载）**

```bash
cd android
./build_android.sh        # macOS / Linux
build_android.bat         # Windows
```

产出同样是 `app/build/outputs/apk/debug/app-debug.apk`。

## 6. 版本号管理（配合在线更新，重点）

每次发新版，**必须**在 `android/app/build.gradle.kts` 里递增版本号：

```kotlin
defaultConfig {
    versionCode = 3   // ★ 每发一版 +1（整数，用于判断是否更新）
    versionName = "1.2"  // ★ 给人看的版本名
}
```

- `versionCode`：整数，必须比上一版大，手机靠它判断"有没有新版本"
- `versionName`：显示用，格式随意（如 `1.2`、`2.0.0`）

## 7. 发布新版（让用户手机自动更新）

完整流程：

```
改代码 → versionCode +1 → 打包 APK
   ↓
网站登录 → 右上角「管理」→ 顶部「版本管理」
   ↓
上传新 APK → 版本号填整数(如 4) → 版本名 → 更新说明 → 点「发布」
   ↓
用户手机 App 下次打开（或「我的 → 检查更新」）自动弹窗 → 一键更新
```

> 你手机上现在装的是 v1.2（versionCode=3）。之后你改完代码、把 versionCode 改成 4、发布后，手机上的 v1.2 就会自动收到更新。

## 8. 常见坑（都提前帮你避掉了）

| 坑 | 说明 |
|---|---|
| JDK 版本 | 必须 JDK 17，工程已在 `gradle.properties` 写死 `org.gradle.java.home`，你不用管 |
| 同步失败 | 点大象图标 🐘 重新 Sync；首次慢是正常的 |
| 预览看不到 | 必须 Android Studio，且打开的是 `android/` 内层目录 |
| 依赖下载慢 | 已配阿里云 Maven + 腾讯 Gradle 镜像，无需翻墙 |
| `--no-daemon` | 只在受限沙箱环境需要；你自己电脑上用 Android Studio/命令行都不用加 |
| 报错 `Unresolved BuildConfig` | 需 `import com.teachingsystem.web.BuildConfig` |
